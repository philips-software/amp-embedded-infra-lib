= GapCentral
:source-highlighter: highlight.js
:highlightjs-languages: protobuf

`GapCentral` implements the BLE GAP central role: scanning, connecting, pairing/bonding, security configuration, and identity/privacy management. All asynchronous callbacks are delivered on `GapCentralResponse`.

== State Constraints

After startup this service is only available after `GapCentralResponse.CurrentState(standby)` has been received. Unless a method's documentation specifies otherwise, all methods are allowed in all link-layer states.
